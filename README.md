# SC1007 Data Structures & Algorithms

Coursework, practice solutions, and worked examples for **SC1007 (Data Structures & Algorithms)**.

## Repository Overview

This repository is organized by topic and assignment.

- `1_LL/` — Linked List practice
- `2_Stack_Queues/` — Stack and Queue exercises
- `3_BT_BST/` — Binary Tree and Binary Search Tree exercises
- `5_AnalysisOfAlgo/` — Algorithm analysis and complexity exercises
- `6_Searching/` — Searching-related questions and datasets
- `7_HashTable/` — Hash table templates and solutions
- `8_Tries/` — Trie templates and answers
- `Assignment1/` — Assignment 1 solutions
- `assignment2/` — Assignment 2 solutions
- `Lect/` — Lecture examples and in-class code
- `ownStuff/` — Personal topic notes and Jupyter notebooks
- `pracT/` — Additional practice tasks

## Requirements

- Python 3.9+ (recommended)
- Jupyter Notebook / JupyterLab (for `.ipynb` files)

## How to Use

### Run Python scripts
From the repository root:

```bash
python <path-to-script>.py
```

Example:

```bash
python 1_LL/L1Q1.py
```

### Open notebooks

```bash
jupyter notebook
```

Then open any notebook file such as:
- `1_LL/tut1.ipynb`
- `2_Stack_Queues/tut2.ipynb`
- `3_BT_BST/tut3.ipynb`

## Notes

- Most files are independent exercises and can be run separately.
- Some scripts use provided input files in the same folder (for example in `5_AnalysisOfAlgo/` and `6_Searching/`).
